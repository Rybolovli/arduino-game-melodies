# arduino-game-melodies
The correct Arduino sketch: Super Mario / Star Wars
## Проекты
- sketch_super_mario.ino — тема Супер Марио
- sketchstarwars.ino — тема Звёздных войн

## Как использовать
1. Откройте файл .ino в Arduino IDE
2. Подключите пьезодинамик к плате
3. Загрузите скетч на Arduino
